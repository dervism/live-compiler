About Live Compiler

A small editor that compiles your code as you type and shows the assembly, the program’s output and the compiler’s messages side by side.

How it works

  1. When you stop typing for about 0.8 seconds (or press Ctrl+Enter), the source, the chosen compiler and your flags are sent to the Compiler Explorer API at compiler-explorer.com.
  2. Compiler Explorer compiles the code and, where the compiler supports it, builds and runs the program.
  3. The response comes back as assembly (or bytecode), program output and diagnostics, shown in their own panels.

Working with the panels

  1. Drag the line between two panels to resize them.
  2. Drag a panel by its title bar onto another one: drop on an edge to dock beside it, or in the middle to swap places.
  3. Show or hide panels from View; pick a ready-made arrangement from Layout.
  4. Put the cursor on a source line to highlight its assembly; hover an assembly line to highlight its source. Click a compiler message to jump to its line.

Code completion and live errors (optional)

Run the companion Docker container and the editor gains completion as you type (after ., :: or ->, or with Ctrl+Space), documentation on hover, parameter hints and red squiggles before you compile. It runs real language servers on your own computer, one container per language (Java, Haskell, C, C++, Rust, Go and Python), so you only install the ones you want. The LSP button in the toolbar shows the connection and opens its settings. Without the container, Ctrl+Space still suggests words from your file.

Privacy and storage

Your code is sent to compiler-explorer.com to be compiled and, if you run the container, to the language servers on your own computer; nothing goes anywhere else. Your code (per language), compiler choices, flags, layout and theme are stored in this browser’s local storage only.
